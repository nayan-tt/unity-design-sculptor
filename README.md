
# Impact Marketplace

A React-based ethical e-commerce website built with:
- React
- TypeScript
- Tailwind CSS
- shadcn/ui components
- React Router

## Getting Started

1. Clone the repository
2. Install dependencies with `npm install`
3. Run the development server with `npm run dev`
4. Build for production with `npm run build`

## Shopify Integration Options

This is a React-based application, not a native Shopify theme. To use with Shopify, consider:

1. Using Shopify's Storefront API to connect this frontend to Shopify's backend
2. Converting components to a Shopify theme with Liquid templating
3. Using this as a headless frontend with Shopify as the commerce backend

## Features

- Responsive design
- Product catalog display
- Ethical impact highlighting
- Category browsing
- Testimonials
